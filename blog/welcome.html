This blog is not a separate application. It is an ordinary page whose body is generated by the server at request time. The page is listed in srvsite.toml like any other, but it also names a page-specific config file (blog.toml) whose shape tells the engine what kind of page it is: because the config contains a [[posts]] array, the engine treats it as a blog.

Each post is a short record in that config file: an id, a title, a date, an author, an optional image, an optional audio file, an excerpt for the preview card, and the name of a body file. The body files are plain HTML, so a post can contain any markup, styling or script you like. There is no database and no build step; editing the config and the body files is the whole workflow.
