To add a page, add a [[pages]] block to srvsite.toml. The block names the URL, the label shown in the top navigation, a page heading, and the body file to paste in. The first block in the file is the homepage. Pages appear in the navigation in the order they appear in the config.

A page can stay as simple as a single body file, or it can name an optional config file to become a data-driven page. The same mechanism that renders this blog can render other kinds of pages: teach the engine a new "signature" array (for example [[faqs]]) and add a case to the renderer.
